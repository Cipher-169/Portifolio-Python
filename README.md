## 📁 Projetos

### 🎮 Minesweeper
Campo minado no terminal. O jogador define o tamanho do tabuleiro e tenta acertar a posição da bomba.

**Como rodar:**
```bash
python mines.py
```
**Exemplo de uso:**
```
Digite uma altura: 5
Digite uma largura: 5
Digite uma posição no formato (linha coluna): 2 3
```

---

### 🔢 Fibonacci
Gera uma sequência de Fibonacci com N elementos definidos pelo usuário.

**Como rodar:**
```bash
python fibonacci.py
```
**Exemplo de uso:**
```
Quantos elementos deseja ver? 8
[0, 1, 1, 2, 3, 5, 8, 13]
```

---

### 📅 Validador de Data
Valida e formata datas no padrão DD/MM/AAAA, verificando formato, mês, dias por mês e anos bissextos.

**Como rodar:**
```bash
python date_validator.py
```
**Exemplo de uso:**
```
Digite uma data no formato (DD/MM/AAAA): 29/02/2024
29 de fevereiro de 2024
```
