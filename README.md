## 📁 Projetos

### 🎮 Minesweeper
Campo minado no terminal. O jogador define o tamanho do tabuleiro e tenta acertar a posição da bomba.

**Como rodar:**
```bash
python mines.py
```
**Exemplo de uso:**
```
Digite uma altura: 5
Digite uma largura: 5
Digite uma posição no formato (linha coluna): 2 3
```

---

### 🔢 Fibonacci
Gera uma sequência de Fibonacci com N elementos definidos pelo usuário.

**Como rodar:**
```bash
python fibonacci.py
```
**Exemplo de uso:**
```
Quantos elementos deseja ver? 8
[0, 1, 1, 2, 3, 5, 8, 13]
```
